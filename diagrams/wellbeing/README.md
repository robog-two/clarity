# Wellbeing features

Design diagrams for outings, stuck tasks and fewer notifications (approved 2026-11-16).

1. `1-overview`: new and changed parts per feature
2. `2-outing`: suggesting something to look forward to
3. `3-stuck`: tasks carried over for days
4. `4-notify`: what notifies and what waits for the evening summary

Rendered with [mermaid-compiler-rust](https://github.com/robog-two/mermaid-compiler-rust):
`mmdc -c mmd-config.json -i 1-overview.mmd -o 1-overview.png -s 2 -b white`
(the config sets DejaVu Sans; PNG text needs that font installed).
